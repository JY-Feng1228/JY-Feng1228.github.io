合成样本模型验证 + 本人验收 · 2026.10.22–23

只有简历写了的，简要提及，不补细节。

公开版使用者通常只上传一份简历。整理时一次读入简历和项目报告，同一项目合并为一段经历；每条事实的引句由程序回到原文定位，判断它出自简历还是项目材料。有项目材料佐证的内容正常展开，只有简历写的按原表述简要提及，不补过程和数字。

上传简历与项目材料↓程序定位每条引句的来源↓有佐证：具体回答 · 仅简历：简要提及

本人验收时发现，逐条确认的表单没人愿意填完，确认一跳过，回答就照着夸大的简历复述。于是改为整理后直接生效，只列出面试官最可能追问的“简历薄弱点”。用一份虚构的夸大简历加项目报告重答同样 9 题：新版 6 题更好、1 题较差、2 题持平，项目事实与报告一致。

等级由程序计算，模型不能自报；数字和“独立、主导”等说法须在项目材料中出现才算佐证。小样本合成题、每题 1 次；只在技能清单出现的工具如何回答，靠关键词规则兜底，覆盖不到所有说法；尚未由第一次使用的他人完成验收。

真实模型重放 · 2026.10.21

需要多步推导时，给模型完整思考的时间。

自动识别计算、逻辑、算法和带约束的设计题，转入高推理；概念与行为题保持快速口答。代码题移除 8 秒简短思路回退和 90 秒截止，等待完整答案。

识别本轮题型↓概念 / 行为：快速口答多步推导 / 代码：高推理完整作答

18 条初始重放中，16 条生成的题型判断全部符合预期，另 2 条只做核查。初始与定向补测中，首字约为：口答 2.0–3.4 秒、推导 5–25 秒、代码 7–15 秒。

重放也暴露了 SQL 输出粒度、修正时误删代码行和计算器缺少对数函数的问题，随后分别修复。小样本合成题，每题每轮 1 次；路由正确不等于内容全部正确，也不代表真人面试效果。

安全加固 + 发行 · 2026.10.21–22

把个人工具交给别人前，先收紧边界。

API Key 通过 Windows DPAPI 加密存储，界面只显示“已配置 / 末四位”。所有 IPC 校验发送窗口、页面和参数；窗口启用沙箱，禁止导航和新窗。

手机显示只绑定所选网络，增加 Host 校验与限流；检测到所选网络地址失效后自动关闭，恢复后需重新配对。

公开版 1.2.1 使用独立数据目录与离线设备授权，使用者自备 Key，结束时默认不保存问答。最终记录为 572 项离线测试通过，并完成实际发行 EXE 的隔离验证。

DPAPI 主要防设置文件被拷走，不能防已被控制的电脑。手机显示仍为明文局域网，仅用于可信 Wi-Fi；安装包未代码签名。

实现 + 一次真实链路试跑 · 2026.10.10

连接回来后，继续处理漏掉的问题。

为系统音频增加最多 60 秒的滚动缓存，连接恢复后按顺序、最高 2 倍速补发；已确认的音频不重复提交。

断网时暂存音频↓重连后顺序补发与转写↓补回问题，避免重复作答

一次 5 分钟试跑中，断网约 20 秒，补发 28.24 秒音频，4/4 题完成。20 秒指断网时长；超过缓存上限会丢弃最早音频，后续长时测试也记录过丢弃。

阶段实验 · 2026.10.16

Codex 定位的具体问题：全量文本标准化，以及长提前期仍取目标日前 7 天负荷，都会让实现使用预测当时不可得的信息。

怎样检验修复

把未来文本数值放大 1,000 倍，训练期的标准化结果仍应保持不变。

发现的问题reference = target − 7 days

当提前期超过 7 天，参考日落在预测起点之后。

修正后的规则lag = ceil(horizon / 7) × 7

按整周回退，保证参考值在预测时已经可用。

同批修复还包括：文本缩放只拟合训练期；用「预测起点 + 提前期」显式对齐目标日期，替代按行移位。

14/14当轮测试通过；210 个模型 × 提前期单元完成产物、哈希与指标一致性检查。

怎样检验恢复

每次成功调用写入原子检查点；提示词、协议、代码、基线、事件数据与模型参数完全匹配才复用。损坏或不匹配时停止。

13新增恢复测试；当轮 38/38 通过，覆盖中断、缺失续跑、哈希不匹配与半写入文件。

结果决定方法的适用范围。

直接 LLM 修正的误差上升，混合方案在所测事件集上更有效。这个结论限定于已测试的模型、数据与设置；更换模型后的效果仍需对照实验验证。

后续如何检验方法的适用范围

保持数据、时间划分、事件、预测提前期与基线一致，比较不同模型的直接修正结果与混合方案。研究评价应检查预测误差、时间安全和结果稳健性。更换模型往往同时改变训练与能力，不能把全部差异归因于参数规模；解释更丰富也不自动代表证据更严谨。

此处为 2026.09 补充的研究复盘与后续验证方向，尚未计作已完成实验。面向能源公司的需求预测应用属于未来可能方向。
